# 현재 적용 레퍼런스

UI Bowl MCP에서 조회한 라운드 앱의 카드 등록·검색 화면 2종만 적용합니다.

- references.json: 출처 링크, 화면 ID와 적용 이유
- image-downloads.json: 현재 이미지 파일 위치와 다운로드 결과
- images/: 실제 저장한 화면 이미지

카드 등록: 흰 배경, 회색 입력 경계와 하단 행동 버튼.
검색: 회색 검색창, 작은 강조 칩과 여백.
두 화면은 같은 앱의 서로 다른 흐름이며, 두 서비스 비교가 아닙니다. 홍보용 형광색 배경은 적용하지 않습니다.

이전 MyTeaPal·Day One·Daylio 자료 및 images 폴더의 현재 목록에 없는 파일은 과거 자료이며 적용 대상이 아닙니다. 이전 목록은 harness/artifacts/history/에 보관됩니다.
