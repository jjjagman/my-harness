# 하네스 역할과 권한

## 작업 에이전트

| 역할 | 담당 작업 | 편집 가능한 폴더 |
|---|---|---|
| 레퍼런스 분석자 | 레퍼런스 수집·공통 패턴 정리 | harness/artifacts/01-references/ |
| 화면 설계자 | 화면 목록·구조·상태 정의 | harness/artifacts/02-structure/ |
| 디자인 규칙 작성자 | 토큰·컴포넌트·판정 규칙 정리 | rules/ |
| 피그마 제작자 | 화면 제작·검사용 데이터 추출 | harness/artifacts/04-design/ |
| 전달 문서 작성자 | 개발자 전달 안내 작성 | harness/artifacts/05-review/ |

- 작업 에이전트별 편집 폴더는 1개로 제한한다.
- 다른 역할의 산출물과 docs/는 읽기 전용이다.
- 다른 역할의 산출물 수정이 필요하면 담당 역할에 돌려보낸다.
- 피그마 제작자의 외부 편집 범위는 지정한 피그마 파일·페이지로 제한한다.
- 전달 문서 작성자는 담당 폴더에서 handoff.md만 편집한다. report.json은 수정할 수 없다.

## 읽기 전용 판정자
- 판정 스크립트를 실행하고 근거를 확인한다.
- 산출물과 규칙을 수정하지 않는다.
- 다음 정보를 반환한다.
  - 규칙 ID
  - 판정: 통과·실패·보류
  - 판정 근거
  - 실패 또는 보류 시 복귀 단계
- 판정 결과는 오케스트레이터가 report.json에 기록한다.

## 오케스트레이터
- 단계 실행, 게이트 호출, 재시도 관리를 담당한다.
- G3에서 디자이너에게 승인을 요청한다.
- 다음 관리 데이터에 쓰기 권한을 가진다.
  - harness/artifacts/run-state.json
  - harness/artifacts/history/의 실행 이력
  - harness/artifacts/05-review/report.json
- 위 권한은 작업 에이전트의 편집 폴더 제한과 별도로 둔다.
- 작업 산출물과 판정 규칙은 직접 수정하지 않는다.
- 판정자가 반환한 결과를 임의로 통과로 변경하지 않는다.

## 자연어 트리거

| 문구 | 동작 |
|---|---|
| 차록다록 디자인 시작 | 새 실행을 시작한다. |
| 이어서 진행 | 입력·규칙·산출물의 변경 여부를 확인하고 재개한다. |
| 검토해줘 | 현재 산출물만 판정한다. |
| 승인 | G3 승인 요청에 제시된 산출물 버전을 승인한다. |

- ‘승인’은 대기 중인 G3 승인 요청이 있을 때만 적용한다.
- 산출물이 변경되면 이전 승인은 무효화한다.
