# 하네스 검증과 리뷰

## 판정 스크립트 검증

| 사례 | 기대 결과 |
|---|---|
| 모든 필수 조건을 충족한 정상 데이터 | 자동 검사 통과 |
| 레퍼런스 출처 URL 누락 | G1 실패 |
| 필수 화면 누락 | G2 실패 |
| 차 이름 외 필수 입력 추가 | G2·G3 각각 실패 |
| 검사 대상 속성의 허용 토큰 위반 | G3 실패 |
| 피그마 검사용 추출 데이터 없음 | G3 보류 |

각 사례는 다른 필수 조건을 충족한 상태에서 검증한다.
예상 결과와 실제 결과의 불일치는 0건이어야 한다.
자동 검사 통과만으로 사람 승인을 대체하지 않는다.

## 실행 제어와 권한 검증

| 사례 | 기대 동작 |
|---|---|
| 변경 없는 완료 단계에서 재개 | 해당 단계 건너뛰기 |
| 입력 변경 후 재개 | 영향을 받는 단계와 후속 검토 재실행 |
| 승인된 산출물 변경 | 이전 검사·승인 무효화 |
| 자동 수정 2회 후에도 미통과 | 실행 중단 및 원인 보고 |
| 작업 에이전트가 담당 범위 밖 쓰기 시도 | 쓰기 차단 |
| 읽기 전용 판정자가 산출물·규칙 수정 시도 | 쓰기 차단 |

각 사례의 기대 동작과 실제 동작의 불일치는 0건이어야 한다.
권한 제한은 문서 선언만으로 검증 완료 처리하지 않고,
실제 쓰기 시도가 차단되는지 확인한다.

## 최종 사람 리뷰
디자이너에게 다음 자료를 제시한다.

- 핵심 화면 5종의 이미지와 피그마 링크
- 자동 검사 결과
- 미해결 항목 목록

디자이너는 다음 3항목을 각각 승인한다.

1. 브랜드색의 절제와 무채색 구성
2. 참고 스타일과의 부합
3. 시각적 가독성

필수 자동 검사 실패 0건·보류 0건과 위 3항목의 승인이 모두 충족되어야 G3를 통과한다.
승인은 검토한 산출물 버전에 연결한다.

## 완료 상태 구분
- 인터뷰 완료: 라운드별 설계 문서와 최종 AGENTS.md가 사용자 승인을 받아 저장된 상태.
- 하네스 검증 완료: 실제 구현 후 모든 필수 검증을 실행하고, 기대 결과와 실제 결과의 불일치가 0건인 상태.
- 실행하지 않은 검사는 미실행으로 기록한다.
- 설계 문서 승인만으로 구현·검증 완료를 선언하지 않는다.

## 검증 결과 기록
각 검증 사례에 다음 정보를 남긴다.

- 사례 ID
- 기대 결과
- 실제 결과
- 실행 여부
- 검증 근거
- 기대 결과 일치 여부
