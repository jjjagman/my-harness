# 하네스 목적

## 적용 범위와 실행 입력
- 차록다록 전용 하네스로 시작한다.
- 실행마다 PRD 변경 내용과 레퍼런스를 입력한다.

## 사용자
- 디자이너 본인 1명이 실행하고 결과를 확인한다.
- 개발자는 최종 산출물을 받는다.

## 완료 기준
디자이너가 PRD의 핵심 화면 5종을 피그마로 제작하고, 합의된 자동 검사 실패 0건과 필수 사람 승인을 확보해 개발자 전달용 산출물을 준비하면 완료다.

- 핵심 화면: 기록 목록, 차 기록 작성, 기록 상세, 내 취향 분석, 기록 항목 설정.
- 화면 5종의 포함 여부를 검사한다. 상태별 변형과 모달을 포함한 전체 프레임 수는 별도로 정한다.
- 자동 검사 항목과 사람 승인 지점은 R5에서 확정한다.
- 개발자 전달용 산출물의 구성은 R4에서 확정한다.

## 실행 환경
- Codex를 사용한다.
- 최종 오케스트레이터 지침은 AGENTS.md로 작성한다.

## 참조 문서
- docs/prd.md: 서비스 요구사항
- docs/design.md: 시각 디자인 기준
- docs/story-service.md: 서비스 목적과 위반 금지 기준
- docs/story-work.md: 실제 작업 순서와 게이트·경계

## 후속 확인 사항
- 기존 작업 흐름의 컨펌 3곳과 R5의 사람 승인 1곳을どう 대응시킬지 R5에서 확정한다.
