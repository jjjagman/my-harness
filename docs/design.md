## Overview

차록다록은 마신 차의 향과 맛, 우림 조건, 그날의 감상을 차곡차곡 쌓는 **개인 차 시음 다이어리이자 취향 라이브러리**입니다. 사용자는 자신에게 필요한 항목으로 시음 경험을 기록하고, 지난 기록을 검색하거나 차 종류별로 살펴보며, 쌓인 기록에서 좋아하는 차와 향미를 발견합니다. 인터페이스는 차를 마시는 시간을 방해하지 않고 기록을 자연스럽게 돕습니다. 순백색 캔버스(`{colors.canvas}` — #FFFFFF)에 짙은 잉크색 텍스트(`{colors.ink}` — #141414)를 사용하고, 옅은 회색 배경과 얇은 경계선으로 정보를 구분합니다. 차와 찻잔 사진, 사용자가 남긴 시음 기록이 화면의 중심이 됩니다.

둥근 형태와 정돈된 여백으로 차록다록의 편안하고 친근한 성격을 표현합니다. 버튼과 필터 칩, 선택 컨트롤은 양 끝이 둥근 캡슐형(`{rounded.full}`)으로 구성하고, 기록 카드에는 `{rounded.md}`(24px), 사진과 입력창에는 `{rounded.sm}`(16px)을 적용합니다. 서체는 Pretendard를 사용하며, 제목은 Bold 700, 본문은 Regular 400, 짧은 도입 문구는 Light 300으로 구분합니다. 전통 다도의 무거운 분위기보다 일상에서 가볍게 펼치는 개인 다이어리의 인상을 지향합니다.

브랜드색인 연한 옐로 라임(`{colors.primary}` — #EEFF95)은 ‘기록하기’와 ‘저장하기’ 같은 주요 버튼 또는 작은 포인트에만 사용합니다. 넓은 배경, 안내 카드, 취향 요약 카드에는 사용하지 않습니다. 나머지 UI는 흰색 #FFFFFF, 본문 #141414, 보조 글자 #737373, 경계선 #E5E5E5, 옅은 배경 #F5F5F5, 보조 상태 #A3A3A3의 무채색으로 구성합니다. 밝은 브랜드색 위에는 짙은 잉크색 문구와 아이콘을 사용하고, 브랜드색 자체를 작은 글자의 색상으로 사용하지 않습니다. 차 사진은 본래의 색을 유지합니다. 취향 분석은 실제 기록이 뒷받침하는 내용만 보여주고, 데이터가 부족한 항목에는 안내를 제공합니다.

현재 적용하는 레퍼런스는 UI Bowl MCP에서 조회한 ‘라운드’ 앱의 카드 등록·검색 화면입니다. 흰 배경, 회색 입력 영역, 작은 강조 영역을 참고합니다. 현재 목록과 이미지 연결의 단일 기준은 `harness/artifacts/01-references/references.json`과 같은 폴더의 `image-downloads.json`입니다. 이전 외부 출처 자료는 현재 디자인에 적용하지 않습니다.

**Key Characteristics:**

- **무채색 중심과 제한된 옐로 라임** — 흰색·회색을 기본으로 사용하고, #EEFF95는 주요 버튼과 작은 포인트에만 적용
- **개인 시음 다이어리이자 취향 라이브러리** — 기록 목록·작성·상세·취향 분석·기록 항목 설정으로 이어지는 경험
- **부담 없는 기록** — 차 이름만 필수로 입력하고, 나머지 항목은 사용자가 표시 여부와 순서를 정해 자신의 기록 방식에 맞게 구성
- **둥글고 편안한 형태** — 버튼·필터 칩은 `{rounded.full}`, 기록 카드는 24px, 사진·입력창은 16px 모서리 사용
- **절제된 깊이 표현** — 강한 그림자 대신 옅은 무채색 배경, 1px 경계선, 여백으로 정보의 위계 구성
- **Pretendard의 굵기 대비** — 제목은 700·행간 1.3~1.35, 본문은 400·행간 1.5, 짧은 도입 문구는 300으로 설정
- **시음 경험이 중심인 화면** — 사진은 실제 색상을 유지하고, 향미 강도와 전체 호감도는 서로 다른 평가 정보로 명확하게 구분
- **기록에 근거한 취향 발견** — 분석 기준을 충족한 항목만 시각화하고, 데이터가 부족한 영역은 추정 대신 필요한 기록 안내 제공
