# 차록다록 유저스토리

출처: [prd.md](prd.md)

## 유저스토리

| 번호 | 유저스토리 | PRD 근거 |
|---|---|---|
| 1 | 로그인한 사용자가 차 이름과 원하는 시음 항목을 입력해 시음 경험을 기록한다. | 화면 2 · 차 기록 작성 |
| 2 | 로그인한 사용자가 최근 기록을 둘러보거나 차 이름 검색·차 종류 필터로 지난 시음 기록을 찾아 확인한다. | 화면 1 · 기록 목록 |
| 3 | 로그인한 사용자가 저장된 시음 기록을 수정하거나 최종 확인 후 삭제한다. | 화면 3 · 기록 상세 |
| 4 | 로그인한 사용자가 취향 분석에서 실제 기록에 근거한 선호 경향과 데이터 부족 안내를 확인한다. | 화면 4 · 내 취향 분석 |
| 5 | 로그인한 사용자가 기본 기록 항목의 표시 여부와 순서를 설정한다. | 화면 5 · 기록 항목 설정 |

## 이 서비스에서 어기면 안 되는 것

| 번호 | 어기면 안 되는 것 | PRD 근거 |
|---|---|---|
| 1 | 차 이름 외 항목의 입력을 강제하지 않고, 사용자가 기록할 항목을 설정할 수 있게 한다. | 화면 2 및 §12 지켜야 할 것 |
| 2 | 취향 분석은 실제 데이터가 충분한 항목부터 제공하고, 요약을 포함해 부족한 취향 정보를 임의로 추정하지 않는다. | 화면 4 · 내 취향 분석 |

PRD의 미확정 사항은 구체화하지 않았다.
