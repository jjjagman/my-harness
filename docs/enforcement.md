# 강제 범위

guard-write.mjs는 역할 밖 저장, 상대경로 이탈, 심볼릭 링크, Windows 대체 데이터 스트림을 차단한다.
scripts/harness.mjs는 선행 게이트, 승인 해시, 재시도 횟수를 검사한다.
판정자는 validate()로만 읽고 결과를 반환한다. 관리 기록은 Harness가 저장한다.

이것은 CLI/API 경계의 강제다. 같은 사용자 권한의 임의 셸, 에디터, MCP 직접 쓰기를 막는 OS 보안 경계는 아니다.
최종 승인 CLI는 대화형 터미널과 3개 명시적 yes 응답을 요구한다. 사용자 신원 인증 체계는 아니다.
Codex 세션 전체의 강제 설정과 외부 Figma 쓰기 제한은 실제 환경에서 별도 검증이 필요하다.
지원 여부가 검증되지 않은 .claude/settings.json이나 Codex 훅 설정을 만들어 작동한다고 주장하지 않는다.
