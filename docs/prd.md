# 차록다록 PRD

**마신 차를 기록하고 나의 취향을 발견하는 개인 차 시음 다이어리**

시음 경험을 한곳에 모아 다시 찾아보고, 쌓인 기록에서 선호하는 차와 향미를 알아가는 앱.

문서 상태: 현재 초안 정리 완료 — 핵심 미확정 사항은 `[확인 필요]`로 표시

## 한 줄 정의

차록다록은 차를 취미로 즐기는 사람이 시음 경험을 자신에게 맞는 항목으로 기록하고 쌓인 기록의 탐색과 분석으로 취향을 확인하는 서비스입니다.

## 1. 배경

### 현재 문제

- 어떤 차를 언제 마셨고 어떤 향과 맛이었는지 시간이 지나면 기억하기 어렵다.
- 기록이 흩어져 있어 자신의 선호를 파악하기 어렵다.

### 해결할 것

- 시음 경험을 부담 없이 남기고 다시 찾을 수 있게 한다.
- 기록이 쌓일수록 자신의 차 취향을 발견하도록 돕는다.

## 2. 타겟 사용자

**주요 사용자 1명:** 차를 취미로 마시기 시작했거나 여러 종류의 차를 경험하고 있는 사람.

마셨던 차의 경험을 기억하고 싶지만 흩어진 기록을 다시 찾는 데 불편을 느끼며, 자신이 어떤 차와 향미를 좋아하는지 알고 싶어 한다.

## 3. 사용자 시나리오

### 시나리오 1 · 차를 마시며 기록하기

1. 기록 목록에서 새 기록을 시작한다.
2. 차 정보와 원하는 시음 항목을 입력한다.
3. 기록을 저장하고 작성한 내용을 확인한다.

### 시나리오 2 · 지난 기록 찾기

1. 다시 마시고 싶은 차를 떠올리며 최근 기록을 둘러본다.
2. 차 이름으로 검색하거나 종류로 필터링한다.
3. 원하는 기록을 선택해 시음 내용을 다시 확인한다.

### 시나리오 3 · 내 취향 발견하기

1. 별도 메뉴에서 내 취향 분석을 연다.
2. 분석 가능한 결과 또는 기록 부족 안내를 확인한다.
3. 요약과 시각화를 통해 선호 경향을 살펴보고 기록을 이어간다.

## 4. 앱 정보 구조

```text
기록 목록 (로그인 후 첫 화면)
  ├─ + 버튼 → 차 기록 작성
  └─ 기록 선택 → 기록 상세
별도 메뉴 → 내 취향 분석
설정 → 기록 항목 설정
```

## 5. 시연 범위 (5개 핵심 화면)

로그인한 상태에서 다음 5개 화면을 시연한다. 수정은 작성 화면을 재사용하고 삭제 확인은 모달로 제공한다.

### 화면 1 · 기록 목록

**목적:** 최근 시음 경험을 둘러보고 원하는 기록을 찾는다.

**주요 요소:**

- 최근 마신 차 기록 목록
- 차 이름 검색, 차 종류 필터
- 새 기록을 시작하는 + 버튼

**Primary 액션:** 기록 선택 → 기록 상세.

### 화면 2 · 차 기록 작성

**목적:** 원하는 항목으로 시음 경험을 남긴다.

**주요 요소:**

- 차 이름만 필수 입력, 나머지 기록 항목은 선택 입력
- 시음 날짜·시간: 기록 시작 시점으로 자동 입력, 사용자 수정 가능
- 차 종류·산지, 우림 정보(차 양·물 양·물 온도·우리는 시간), 사진
- 향미 특성 복수 선택 및 특성별 강도 1~5 기록
- 전체 호감도: 향미 강도와 별개인 1~5 평가
- 단맛·쓴맛·떫은맛·감칠맛·바디감 등 맛·질감 기록

**Primary 액션:** 새 기록 저장 → 해당 기록 상세.

[확인 필요: 기본 향미 분류와 맛·질감 평가 방식]

### 화면 3 · 기록 상세

**목적:** 저장된 시음 내용을 확인하고 관리한다.

**주요 요소:**

- 해당 기록에 저장된 정보와 사진
- 수정: 기존 값이 채워진 차 기록 작성 화면으로 진입하고, 저장 후 해당 상세로 복귀
- 삭제: 확인 모달에서 최종 확인 후 삭제하고 기록 목록으로 이동
- 뒤로 이동: 기록 목록으로 복귀

**Primary 액션:** 시음 내용 확인 및 필요 시 수정·삭제.

### 화면 4 · 내 취향 분석

**목적:** 차 종류, 향미·맛·질감 특성과 강도, 전체 호감도의 관계에서 선호 경향을 발견한다.

**주요 요소:**

- 핵심 문장 요약과 시각화된 결과. 호감도 4~5점인 기록만으로 분석을 제한하지 않음
- 기록 5개 미만에도 진입 가능: 현재 기록 수와 첫 분석까지 필요한 추가 기록 수 안내
- 5개 이상: 실제 데이터가 충분한 분석 항목부터 결과 제공
- 특정 항목의 데이터가 부족하면 해당 영역에만 안내하고 다른 분석 결과는 유지. 요약을 포함해 부족한 취향 정보를 임의로 추정하지 않음

**Primary 액션:** 분석 가능한 결과와 데이터 부족 안내 확인.

구체적인 분석 알고리즘과 차트 형태는 미정이다.

[확인 필요: 항목별 분석에 필요한 데이터와 충분성 기준]

### 화면 5 · 기록 항목 설정

**목적:** 자신의 기록 방식에 맞게 입력 항목을 구성한다.

**주요 요소:**

- 기본 제공 항목의 표시·숨김 및 순서 변경. 차 이름은 항상 표시하며 숨김 불가
- 최초에는 일부 항목만 표시하고 나머지는 필요에 따라 켜기
- 숨김은 이후 작성 화면의 표시 여부에 적용. 기존 값은 삭제하지 않고 기록 상세에서 계속 표시

**Primary 액션:** 설정 편집 → 저장 버튼으로 적용.

[확인 필요: 최초에 표시할 항목과 기본 순서]

## 6. 시연 대상 외 화면

- 로그인 / 회원가입: 서비스에는 필요하지만 이번 핵심 화면 제작에서 제외

## 7. 권한 구조

로그인 기반 서비스이며 기록은 사용자 계정에 귀속된다. 추후 다른 기기에서도 같은 기록을 볼 수 있도록 계정 기반으로 관리한다.

| 이용 상태 | 접근 |
| --- | --- |
| 로그인 전 | 서비스 이용을 위해 로그인 필요 |
| 로그인한 사용자 | 자신의 기록 조회·작성·수정·삭제, 항목 설정, 취향 분석 |

## 8. 데이터 모델

화면과 핵심 기능을 위한 개념 모델이다. 입력 정책은 화면별 요구사항을 따른다.

| 객체 | 주요 정보 |
| --- | --- |
| 사용자 계정 | 시음 기록의 소유 주체 |
| 시음 기록 | 차 이름·종류·산지, 시음 일시, 우림 정보, 사진, 전체 호감도 |
| 특성 평가 | 시음 기록에 연결된 향미·맛·질감 특성 및 강도 |
| 기록 항목 설정 | 기본 항목의 표시 여부와 순서 |

같은 차를 여러 번 마셔도 우림 조건이나 마신 시점에 따라 각각 별도의 시음 기록으로 저장한다.

## 9. 브랜드 방향

- **톤:** 차분하고 편안하면서도 귀엽고 친근한 개인 차 다이어리. 전통 다도나 고급스럽고 무거운 브랜드 인상은 피함
- **스타일:** 손그림 일러스트, 종이·크레용 질감, 약간 불규칙한 형태를 활용한 따뜻함
- **컬러 방향:** 아이보리·크림 바탕에 녹색·주황·하늘색·분홍 등 자연스럽고 부드러운 포인트. 지나치게 저채도로 정적이기보다 생기 있는 인상
- **활용 원칙:** 찻잔·찻잎·꽃·과일 등의 작은 일러스트는 보조적으로 사용하며 기록·분석 정보의 가독성 유지
- **무드 레퍼런스:** [사용자 제공 이미지](design/01-references/raw/charokdarok-visual-mood.jpg)

확정된 로고나 브랜드 자산은 없다. 구체적인 색상·로고·자산은 이후 디자인 단계에서 결정한다. 무드 이미지는 스타일 참고용이며 허들링의 자산을 차록다록의 자산으로 사용하지 않는다.

## 10. 참고 앱 / 레퍼런스 방향

UI Bowl에서 차 앱에 한정하지 않고 기록 앱, 다이어리, 음식·음료 기록, 취향 분석 서비스의 UI 패턴을 탐색한다.

- 빠르게 기록하는 경험
- 과거 기록을 검색·필터링하는 경험
- 기록이 쌓이면서 취향을 발견하는 경험
- 기록 항목의 표시·순서를 설정하는 경험

특정 앱은 아직 선정하지 않았으며, 이후 조사에서 출처와 참고 이유를 정리한다.

## 11. 평가 기준

1. **기록의 부담:** 차를 마시는 흐름을 해치지 않고 자신에게 맞는 방식으로 기록할 수 있는가
2. **회고의 편의:** 지난 시음 경험을 쉽게 찾고 확인·관리할 수 있는가
3. **취향 발견의 신뢰성:** 실제 기록에 근거한 선호 경향과 분석의 한계를 이해할 수 있는가
4. **브랜드와 가독성:** 따뜻하고 친근한 다이어리의 개성을 유지하면서 정보를 명확하게 전달하는가

## 12. 지켜야 할 것 / 안 할 것

### 지켜야 할 것

- 모든 항목의 입력을 강제하지 않고 사용자가 기록할 항목을 설정할 수 있게 한다.
- 기록 정보가 많더라도 실제 차를 마시면서 부담 없이 기록할 수 있어야 한다.

### 안 할 것

- 다른 사용자와의 커뮤니티 및 기록 공유 기능
- 차 구매·판매 커머스 기능

## 13. 제외 사항

위 ‘안 할 것’과 시연 대상 외 화면에 더해, 사용자가 새로운 기록 항목을 직접 만드는 기능은 이번 범위에서 제외한다.

## 한 줄 요약

차록다록은 자신만의 방식으로 시음 경험을 쌓고, 지난 기록을 다시 찾으며, 좋아하는 차와 향미를 발견하는 개인 기록 앱이다.
